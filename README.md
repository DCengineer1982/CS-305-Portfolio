# CS-305 Software Security Portfolio

## Artemis Financial – Secure Software Project

### Project Overview

This project focused on improving the security of a web application for Artemis Financial. The objective was to strengthen the application's security by implementing secure communication, verifying data integrity, and identifying vulnerabilities that could place sensitive information at risk. Throughout the project, I applied secure coding practices while ensuring the application continued to function correctly.

---

# Reflection

## Client Summary

Artemis Financial is a financial services company that wanted to improve the security of its software application. The company needed a solution that would better protect customer data and reduce security risks by using secure communications, data integrity verification, and vulnerability analysis.

## What I Learned About Software Security

One of the biggest lessons I learned during this project was that software security should be built into the development process instead of being treated as an afterthought. Using tools like OWASP Dependency-Check helped me identify vulnerable dependencies and understand how third-party libraries can introduce security risks.

Writing secure code is important because it protects sensitive information, improves system reliability, and helps organizations maintain customer trust. Addressing security early in development also reduces the cost and effort of fixing vulnerabilities later.

## Challenges and Improvements

The most challenging part of this project was configuring HTTPS and generating a certificate for secure communication. Although it required careful troubleshooting, completing this step gave me a much better understanding of how encrypted communication protects data exchanged between users and applications.

I also gained valuable experience implementing SHA-256 hashing to verify data integrity and performing dependency scans to identify known vulnerabilities. These activities showed me how multiple layers of security work together to create a more secure application.

## Testing and Validation

After making each security enhancement, I rebuilt the application and tested it to make sure everything still worked as expected. I verified that secure communication was functioning correctly, checksum generation produced the expected results, and the application continued to build successfully after the security modifications. Running dependency scans also helped confirm that no additional security concerns had been introduced.
